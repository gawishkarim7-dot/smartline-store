# Smart Line Store

متجر إلكتروني لشركة الخط الذكي للصناعة (معدن وخشب) — عربي / إنجليزي.

## التشغيل

| الملف | الاستخدام |
|------|-----------|
| **`start.bat`** | تشغيل عادي بدون Docker (Laragon / XAMPP) |
| **`start-docker.bat`** | تشغيل بـ Docker Desktop |
| **`stop-docker.bat`** | إيقاف حاويات Docker |

التفاصيل: **`INSTALL_AR.md`**

- المتجر: http://localhost:8007
- الإدارة: http://localhost:8007/admin
- دخول الأدمن: `admin@smartlinesa.net` / `SmartLine@2026`
- تغيير الحساب: لوحة الإدارة → إعدادات الحساب

## الدفع

تحويل بنكي لحساب الشركة (بنك الرياض). بوابة الدفع الإلكتروني معطّلة افتراضياً.
